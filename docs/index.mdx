# Taste Lint

Catch AI slop before you ship.

Mechanical checks decide what a regex or a measured value can decide. Judgement calls go to [Jev by TypeSafe AI](https://docs.typesafe.ai/introduction), which answers with a probability.

## Install

```bash
npx taste-lint@latest init
```

Requires Node 24.11 or later. Run it from your project directory. Init installs locally and adds a `taste` script.

## Quickstart

```bash
npm run taste -- --dry-run
```

That runs every mechanical check with no key and no model calls. To add Jev review notes, create a [Vercel AI Gateway key](https://vercel.com/docs/ai-gateway/authentication-and-byok/api-keys):

```bash
export AI_GATEWAY_API_KEY="your-vercel-ai-gateway-key"
npm run taste
```

Jev checks send the selected text and rule context to Vercel AI Gateway, billed to your account. Repeat runs reuse cached answers.

## What it checks

- **Product interfaces:** copy, typography, interaction and motion in JSX, TSX and CSS.
- **Writing:** Markdown, MDX and READMEs with `--profile writing`.
- **Agent instructions:** AGENTS.md, skills and plans with `--profile instructions`.

Rules come from [Agent Skills](https://github.com/mblode/agent-skills) and [Taste Training](https://blode.co/taste-training).
