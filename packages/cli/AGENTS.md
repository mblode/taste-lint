# packages/cli

This package has no source of its own. It is the npm-publishable shape of the CLI in root `src/` and `data/`, not a second copy of it. `dist/` and `data/` here are gitignored, build output staged from the root, never edited directly.

## Boundary

- Publishes as `taste-lint` on npm. `exports["."]` is `dist/index.js` (built from root `src/index.ts`); `bin.taste-lint` is `dist/cli.js`.
- Nothing in this monorepo imports from `packages/cli`. `apps/web` does not depend on it. The only consumer inside the repo is `scripts/test-package.mjs` (`npm run test:package`), which packs this directory and installs it into a temp project the way an external npm consumer would.
- Never add source files here. Edit root `src/` and `data/rules/`; this directory is regenerated by `build`, never hand-maintained.
- Never publish from here directly (no `npm publish` in this directory). Releases go through root `npm run changeset` and the Release workflow.

## Commands

Run from the repo root, or with `--workspace packages/cli`; both are verified equivalent (the package's own scripts `cd ../..` first).

```bash
npm run build:cli       # turbo build --filter=taste-lint: tsdown builds root src/ into dist/cli.js
                         # and dist/index.js, then scripts/stage-package.mjs copies dist/, data/,
                         # README.md, LICENSE.md from root into packages/cli/
npm run typecheck:cli    # tsc -p tsconfig.typecheck.json against root src/
npm run test:cli          # vitest run against root src/__tests__
npm run test:package      # packs this staged package and installs it in a temp dir; the real
                           # check that the published shape works for an external consumer
```
