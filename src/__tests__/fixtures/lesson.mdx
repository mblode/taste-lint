# Make text feel right

A "powerful" platform for teams that need to "move fast". Everything you need.

<Callout type="rule">
  Fix in order: copy, type, spacing and craft, then motion.
</Callout>

## Measure

Body reads well between 45 and 75 characters; the sweet spot is 66. Use `"straight"` quotes only in code.

```css
p {
  font-size: "16px";
}
```

- Keep the first item short
- The second item repeats an idea without adding evidence
